# Changelog — SEO Bunny

All notable changes to **SEO Bunny** (by **Mal**) are documented in this file.

## [2.1.0] - 2026-11-09

- Added a fictional interactive demo, first-use guide, browser setup status, and demo screenshots.
- Distinguished failed and ambiguous captures from checked locations; retry preserves prior runs.
- Added matched-checkpoint change summaries and excluded unchecked locations from rank metrics.
- Protected every API route with local host/origin checks and stopped returning proxy passwords.
- Added a separate shareable rank export, retaining private workspace backup compatibility.
- Updated Electron and web dependencies; desktop schema setup now uses built-in SQLite.
- Removed automatic destructive web database updates and excluded private files from desktop resources.
- Added source preflight, Windows/Linux checks, security notes, MIT license, and release documentation.
## [2.0.0] - 2026-11-09

### Added
- Rebranded platform to **SEO Bunny** authored by **Mal**.
- New artisanal Warm Vanilla Cream, Terracotta, Matcha Sage, and Espresso palette across the entire application, charts, maps, and PDF/XLSX exports.
- Client Growth Studio with Review Inbox, Post Studio, local SVG QR code generator, Contacts CRM, and Profile Checklist.
- Encrypted Google Business Profile OAuth 2.0 (PKCE) integration with atomic publishing claims and automatic cache housekeeping.
- Database-backed review collection jobs with immutable run snapshots, coverage classification, and transactional workspace backups.
