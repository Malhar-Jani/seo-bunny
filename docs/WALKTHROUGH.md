# A quick walkthrough

1. Open `/demo`. Every business, rank, and review in this page is fictional.
2. In **Rank map**, select a pin or use the checkpoint buttons below the map.
   The question-mark pin represents a failed capture, not a ranking loss.
3. Read the summary: top-three coverage uses checked locations only. Run changes
   use coordinates successfully checked in both runs.
4. Open **History**, choose **Earlier run**, and return to the map. Select
   **Latest run** to compare how the same area changes.
5. Open **Competitors** and **Reviews** for the sample comparison and authored
   review themes. They demonstrate the interface; they are not client results.
6. Choose **Export sample** for a labelled JSON file, or **Reset demo** to start
   over. Nothing is written to the workspace database.

When ready to use real data, choose **Start your own scan**. The optional Google
connection lives under Settings and is only needed for official profile actions.
